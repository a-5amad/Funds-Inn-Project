# ICT Lab Project

A responsive multi-page website developed as a university project using **HTML and CSS**, with a focus on structured layouts, navigation, forms, and user interface design.

## Features

* Responsive multi-page website
* Home page with structured content and navigation
* About and FAQ sections
* User login and registration pages
* Account page
* Terms & conditions page
* Consistent styling and navigation across pages

## Technologies Used

* **HTML5** — Page structure and semantic markup
* **CSS3** — Styling, layouts, and responsive design

## Pages

* Home
* About
* FAQ
* Login
* Register
* Account
* Terms & Conditions
